# Daily Transit Ridership Analysis

This project analyzes the Daily Transit Ridership dataset obtained from Data.gov.

## Project Goal

The goal of this project is to examine how transit ridership changed over time and compare ridership among different transit agencies.

## Dataset

Source: Data.gov  
Dataset: Daily Transit Ridership

https://catalog.data.gov/dataset/daily-transit-ridership

The dataset contains 211 records and includes information about transit agency, mode, date, week number, current ridership, and year.

## Analysis

The project investigates three questions:

1. How does average transit ridership vary by week of the year?
2. How does transit ridership compare among the three transit agencies?
3. What are the highest and lowest ridership periods in the dataset?

## Tools Used

- Pandas
- Matplotlib
